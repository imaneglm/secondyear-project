# Delivery Company Website

 This project is part of the curriculum of second-year Computer Science and consists of a web-based application for a delivery company platform. This application provides users with the possibility to create an account, log in, and monitor their deliveries. And for staff members to guide customers and enhance the overall client experience, and also find out information on services offered by the company. The key focus of this project is to utilise the concepts of full-stack development by actually providing an implementation for a client-server architecture.

 The described project was group work. I personally had the responsibility of developing the frontend part of the application, contributing to the design and implementation of the database. 

# Technologies Used
React.js (Frontend).
Node.js & Express.js (Backend).
PostgreSQL (Database).
HTML, CSS, JavaScript.
Authentication was handled using JSON Web Tokens (JWT), and passwords were securely stored using bcrypt.
